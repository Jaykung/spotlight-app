# Spotlight 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Summary
A social photo-sharing app called Spotlight built with Expo + React Native. It has a feed, stories, post creation, bookmarks, notifications, profile pages, and user authentication; the backend is Convex and uses Clerk for sign-in. The data model includes users, posts, likes, comments, follows, bookmarks, and notifications, so the app is clearly modeled as a modern social/mobile networking experience similar to Instagram-style feeds and user profiles.

## Features
- User authentication and profile setup with Clerk
- Social feed showing recent posts from followed users
- Story section at the top of the feed
- Create and publish new posts with images and captions
- Like posts and add comments
- Follow/unfollow users and track follower/following counts
- Personal profile screen with bio, stats, and user details
- Bookmark saved posts for later viewing
- Notifications for likes, comments, and new follows
- User detail pages to view another person’s profile and activity
- Backend data modeled with Convex for users, posts, likes, comments, follows, bookmarks, and notifications
- Mobile app built with Expo + React Native for cross-platform use on Android/iOS/web
